Choose an installation path

  • Runtime only: npm package @kujolang/kujo-runtime@1.9.0 runs Kujo programs.
  • Core installer: installs the runtime and separately versioned tools. Pin tool snapshots independently when reproducing a run.
  • Kennel: installs Kujo packages and CLI tools; consult each package’s release requirements.
  • Host plugins use their host’s installer. OpenCode also requires a supported Node version: 22.23.4+, 24.22.1+ or 26.12.1+ in those major lines.
  • Source is an experimental self-hosted Node/Git/npm application, installed separately from Kennel. It has no thousand-agent certification.
