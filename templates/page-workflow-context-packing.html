Pack context within a budget

Select whole passages within a byte budget and reject citations to omitted sources.

Offline demo + live modeDownload application ↓

What you will build

Two short passages fit the context budget. A longer appendix is skipped, and the answer can cite only the selected passages.

Output artifact

context-answer.json

Saved locally for you to inspect and use.

main.kujo

Source ↓
from common import load, save, config, request, require_result

let input := load("input.json")
let budget_check := json_schema_validate(input["budget_bytes"], {"type": "integer", "minimum": 2})
assert(budget_check["valid"], "Budget must hold at least an empty JSON array")
mut selected := []
mut selected_ids := []
mut omitted := []
mut seen := []
for passage in input["passages"] {
    assert(!contains(seen, passage["id"]), "Duplicate passage ID")
    seen = push(seen, passage["id"])
    let candidate := push(selected, passage)
    if byte_length(to_json(candidate)) <= input["budget_bytes"] {
        selected = candidate
        selected_ids = push(selected_ids, passage["id"])
    } else {
        omitted = push(omitted, passage["id"])
    }
}
if len(selected) == 0 {
    save("context-answer.json", {"status": "insufficient_context", "omitted_ids": omitted})
    print("No passage fits. Increase the context budget and rerun.")
    exit(0)
}
let result := request(config(), "Answer from the selected passages and cite their IDs. Do not invent sources.", {"question": input["question"], "passages": selected}, "responses.json", load("schema.json"))
let data := require_result(result)
for id in data["source_ids"] {
    assert(contains(selected_ids, id), "Citation points outside the selected context")
}
save("context-answer.json", {"answer": data, "selected_ids": selected_ids, "omitted_ids": omitted, "context_bytes": byte_length(to_json(selected)), "status": "needs_review"})
print("Saved context-answer.json with the selected and omitted source IDs.")

Run it locally

Start offline.

Install Kujo, download the application, then run these commands from your download directory.

unzip context-packing.zip -d context-packing
cd context-packing
kujo run main.kujo

The ZIP includes main.kujo, common.kujo, input, schema, response fixtures and README.md. Run inside its extracted directory. No key or network request is needed in offline mode.

Read the shared request policy ↗

Offline responses are authored test fixtures. They demonstrate control flow, not live model quality.

How it works

  1. Read passages in caller-supplied priority order and reject duplicate IDs.
  2. Measure the serialized passage array in UTF-8 bytes before adding each passage.
  3. Send the selected context and check every returned citation ID.

Try a failure. Then recover.

Set budget_bytes to 2. No passage fits, so the application writes insufficient_context without a model call. Restore the budget to recover. A citation to the omitted appendix is also rejected.

Use a fresh extraction to restore the original fixtures. A failed run does not make an older output file current; check the exit status before consuming results.

Connect a live provider

Live mode sends your input to the configured provider and may cost money. Choose an OpenAI-compatible endpoint and model you can access, then set credentials in your environment. The example sends at most 1,024 output tokens per request and normally allows two attempts. The batch and regression examples apply that limit per item.

export KUJO_WORKFLOW_MODE=live
export KUJO_AI_ENDPOINT=https://your-provider.example/v1/chat/completions
export KUJO_AI_MODEL=your-model
# Set KUJO_AI_KEY securely in your environment.
kujo run main.kujo

Live transport was tested against a controlled local HTTP server, including failure and timeout cases. No paid provider call or claim about model quality is part of this demo.

Make it yours

Rank your passages before running the application. This example budgets the serialized context array only; reserve space for the question, instructions, schema and answer separately.

Know the boundary

Bytes are not model tokens. This is a predictable context-size limit, not a provider token-limit guarantee. Citation IDs establish source membership, not whether a claim is supported.
