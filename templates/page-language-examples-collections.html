Collections

Combine arrays and dictionaries into a report.

# Expected output:
# build total: 42

let scores := [8, 13, 21]
let report := {"name": "build", "total": scores[0] + scores[1] + scores[2]}

print(report["name"] + " total: " + to_string(report["total"]))

Save as collections.kujo, then:

kujo run collections.kujo
Expected output
build total: 42
