Error handling

Catch a thrown error and continue execution.

# Test better error messages with try/except
func process(x) {
    if x == 0 {
        throw("Cannot process zero value")
    }
    return x * 2
}

try {
    result := process(0)
    print("Result:", result)
} except err {
    print("Error caught:", err)
}

print("Program continues after error handling")

Save as errors.kujo, then:

kujo run errors.kujo
Expected output
Error caught: Error { line: 0, message: Cannot process zero value, stack: [process] }
Program continues after error handling
