Variables and types

Bind values with let and print strings.

# Expected output:
# tool: kujo
# status: ready

let tool := "kujo"
let status := "ready"

print("tool: " + tool)
print("status: " + status)

Save as variables.kujo, then:

kujo run variables.kujo
Expected output
tool: kujo
status: ready
