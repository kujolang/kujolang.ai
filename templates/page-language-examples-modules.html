Modules and imports

Inspect dotted imports and named imports.

Parse-only upstream tour. The imported modules are intentionally not supplied; this is not a standalone runnable program.

# Parse-only module import tour.
# To run this pattern, create the imported files beside your script or inside a package root.

import math_helpers
from metrics import average, total
from src.util import value
from src.core.math import add

Save as modules.kujo, then:

kujo check modules.kujo
