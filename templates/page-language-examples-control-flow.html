Control flow

Choose a branch based on a comparison.

# Expected output:
# pass: build score

let score := 42

if score >= 40 {
    print("pass: build score")
} else {
    print("retry: build score")
}

Save as control-flow.kujo, then:

kujo run control-flow.kujo
Expected output
pass: build score
