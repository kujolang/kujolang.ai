Accumulate a total

Update a running total as a loop visits each number.

Executed offlineMore in Basics ↗

loop-scope.kujo

Download ↓
sum := 0
for n in [1, 2, 3, 4, 5] {
    sum := sum + n
    print("Current sum:", sum)
}
print("Final sum:", sum)
