Make a run reviewable

Accountability means being able to inspect the task, allowed operations, executed checks and recorded result. Kujo provides separate language primitives and tools for these stages. You configure the connections and retain responsibility for permissions and release decisions.

Clarity: define what success means

Spec expresses task contracts. Eval checks declared assertions; Lens records configured browser evidence. Passing checks establish only the assertions exercised under the recorded conditions.

Context: preserve the evidence

Scout inspects repositories and Scent prepares bounded context. RunLedger records runs; PatchBrief summarizes diffs. Receipts describe observed work; hashes do not make them signed attestations or prove a business operation succeeded.

Watchdog records local SQLite telemetry with optional exports. Cost estimates are not provider invoices.

Control: configure authority before execution

Runtime restrictions are opt-in; the default trusted runtime is not a sandbox. Workcell supports Docker and Podman isolation with explicit engine and policy configuration. Remote adapters are alpha. Ability defines operation contracts; hosts supply identity, authorization, handlers and stores. Private gateway services are separate from the public read-only catalog.

Dispatch records workflow state and enforces replay admission. Bounded single-effect recovery is opt-in beta; participant support is alpha. These mechanisms do not promise universal machine-loss recovery or exactly-once external effects.

Replay recorded responses, then check the result

Strict runtime cassettes replay recorded model responses without live model calls. Fallthrough can reach the network. This does not replay arbitrary files, tools or side effects. Run the cassette example and inspect its fixture.

Agents SDK supplies agent runtime primitives. Cancellation and timeouts are cooperative; cost limits depend on host and provider accounting. Keep operational budgets and access controls explicit.

Inspect a concrete workflow

Follow the test-and-evidence workflow, choose an existing coding-agent integration, and review runtime security boundaries. The review guide explains how to connect evidence to a human decision.
