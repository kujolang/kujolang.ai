Client configuration and troubleshooting

For clients that support remote Streamable HTTP MCP servers, set the URL to the endpoint above. If a client reports a connection error, confirm HTTPS access, use the health URL, and ensure the client sends JSON-RPC over POST with Content-Type: application/json. The public service does not accept writes, shell commands, authentication, or arbitrary URL fetching.
