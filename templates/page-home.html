Questions

Start with the boundaries.

What is Kujo?

Kujo is a VM-first programming language built in Rust for AI-native software, local-first automation, agentic workflows, and practical application scripting.

Is the ecosystem one large framework?

No. It is a collection of focused, composable projects. Use the language alone, add primitives such as Eval or the AI SDK, or adopt a complete operating loop.

Does Kujo require hosted AI services?

No. Core workflows are local-first, and many AI surfaces include deterministic offline fixtures. Live providers are explicit integration boundaries.

Where should I begin?

Read the docs for the language, then explore the ecosystem map based on the problem you are solving.
