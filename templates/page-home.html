The Kujo programming language

Trust at the speed of AI.

Kujo is an AI-native programming language for local-first automation and practical application scripting. Its Rust-based runtime executes code on a bytecode VM, with checking, testing and editor tools in the CLI.

Functions and operators

Sum a collection with a reusable function.

# Expected output:

func total(values) {
    mut sum := 0
    for value in values {
        sum = sum + value
    }
    return sum
}

let scores := [8, 13, 21]
print("total: " + to_string(total(scores)))

Save as functions.kujo, then:

kujo run functions.kujo

Deterministic AI request IDs

Compare request identities without credentials affecting the hash.

The credential strings are dummy values. This example makes no network request.

func kv(label, value) {
    print(label + ": " + value)
}

let options_a := {
    "endpoint": "https://api.example.test/v1/chat/completions",
    "model": "gpt-demo",
    "api_key": "credential-one",
    "headers": {
        "Authorization": "Bearer credential-one",
        "X-App": "kujo"
    },
    "body": {
        "temperature": 0,
        "max_tokens": 32
    }
}

let options_b := {
    "endpoint": "https://api.example.test/v1/chat/completions",
    "model": "gpt-demo",
    "api_key": "credential-two",
    "headers": {
        "Authorization": "Bearer credential-two",
        "X-App": "kujo"
    },
    "body": {
        "temperature": 0,
        "max_tokens": 32
    }
}

let hash_a := ai_request_hash("Summarize Kujo", options_a)
let hash_b := ai_request_hash("Summarize Kujo", options_b)

kv("hash_length", to_string(len(hash_a)))
kv("same_without_credentials", to_string(hash_a == hash_b))
kv("hash", hash_a)

Save as request-hash.kujo, then:

kujo run request-hash.kujo
Expected output
hash_length: 64
same_without_credentials: true
hash: a6244047c108dcf58a952ed0a6c70dc04d13ee9aa9dba08eeb623f241fbd37ce

AI calls and replay

Replay a recorded model response offline.

Run from the pinned Kujo repository root: the cassette fixture directory is required.

func kv(label, value) {
    print(label + ": " + value)
}

let options := {
    "endpoint": "http://127.0.0.1:1/v1/chat/completions",
    "model": "gpt-replay",
    "cassette": {
        "mode": "replay",
        "dir": "tests/fixtures/ai_cassettes"
    }
}

let result := ai_chat("Hello model", options)

kv("replay_result", to_string(result))

Save as replay.kujo, then:

kujo run replay.kujo

Conventional languages already offer async functions, HTTP clients and testing libraries. Kujo adds AI request identity, replay, streaming callbacks and capability controls at the runtime level. These mechanisms support review; they do not guarantee correctness or isolation.

Choose Kujo for scripts and tools that benefit from those primitives. Keep Python or TypeScript when existing libraries, deployment requirements or team experience matter more. Independent Kujo tools can still inspect and evaluate those repositories.

What belongs to which layer?
  • Language: functions, modules, collections, structs, enums, matching, async and generators.
  • Rust VM/runtime: execution, host helpers, AI primitives and capability-aware access.
  • Core CLI: check, format, lint, tests, LSP and documentation generation.
  • Separate packages: Kennel, Agents SDK, AI SDK and workflow tools have their own installation and versions.
  • External systems: live model providers require configuration and credentials; optional hosts and integrations are not bundled language features.

Your first successful program

Install. Check. Run.

For a runtime-only install on supported macOS, Linux and Windows systems with Node.js 18 or newer:

npm install --global @kujolang/kujo-runtime@1.9.0
kujo --version

Save print("Hello, Kujo!") in hello.kujo:

kujo check hello.kujo
kujo run hello.kujo

Expected output: Hello, Kujo!. Native installers, Windows guidance and troubleshooting.
