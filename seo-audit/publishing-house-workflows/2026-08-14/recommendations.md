# Recommendations and measurement plan

Audit date: 2026-08-14

## Immediate after deployment

- Verify the catalog and all eight detail routes return HTTP 200 with the expected canonical, Open Graph image, and 0.3.0 release identity.
- Confirm the deployed sitemap contains all eight canonical URLs and `robots.txt` still declares the sitemap.

## 7-day checks

- If provider access is available, inspect sitemap processing and index coverage without treating submission as an indexing guarantee.

## 28-, 60-, and 90-day comparisons

- Compare impressions, clicks, indexed URL state, referral traffic, and field performance only from like-for-like provider windows.
- Re-run controlled AI citation questions only when authenticated sessions and evidence capture are available.

## Editorial decisions

- Keep each page aligned with its workflow contract and update release identity only when the repository release changes.
- Preserve the distinction between installable offline fixtures and operator-configured live publication authority.
