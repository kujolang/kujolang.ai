# Follow-up measurements

Compare the same Source URLs at 7, 28, 60 and 90 days after deployment (2026-10-21, 2026-11-11, 2026-12-13, 2027-01-12). Check index coverage, impressions, clicks, query intent, crawler access and field performance using owner-authorized data. Repeat controlled questions such as “What is Kujo Source?”, “How does Source approve agent changes?” and “Does Source run on Cloudflare?” Record platform/date, actual citations and factual errors. Do not treat a missing answer as proof of a crawler problem.
