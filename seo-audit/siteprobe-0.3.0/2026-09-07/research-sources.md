# Primary guidance

Retrieved during this audit; applicability is limited to the release update.

| Source | Classification | Supported conclusion |
| --- | --- | --- |
| https://developers.google.com/search/docs/appearance/ai-features | Official recommendation | Standard SEO, indexable useful content and crawlable links apply to AI features; no special AI file or schema is required. |
| https://developers.google.com/search/docs/fundamentals/using-gen-ai-content | Official recommendation | Preserve factual accuracy and useful original information, including titles, descriptions and structured data; do not mass-produce filler. |
| https://developers.openai.com/api/docs/bots | Official crawler documentation | Search discovery, training and user-triggered agents have distinct purposes; preserve the owner's training policy and inspect access separately. |
| https://schema.org/SoftwareApplication | Vocabulary definition | Software properties must describe real product facts; vocabulary validity does not establish rich-result eligibility. |
| https://github.com/kujolang/siteprobe/releases/tag/v0.3.0 | Primary release evidence | Native Kujo release, four source packages, exact runtime requirement and versioned compatibility boundaries. |
