# Research sources

Audit date: 2026-08-10

| Source | Retrieved | Supported conclusion | Classification |
| --- | --- | --- | --- |
| [Google SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide) | 2026-08-10 | Crawlable links, canonicalization, unique descriptive metadata, useful original content, and accessible resources remain core SEO practices; meta keywords are not used. | Official recommendation |
| [Google title links](https://developers.google.com/search/docs/appearance/title-link) | 2026-08-10 | Every page should have concise, descriptive, distinct title text aligned with its visible main title. | Official recommendation |
| [Google site names](https://developers.google.com/search/docs/appearance/site-names) | 2026-08-10 | Home-page `WebSite` structured data should use a consistent name and canonical root URL; `alternateName` is supported. | Official recommendation |
| [Google generative-AI optimization guide](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide) | 2026-08-10 | Core SEO and Search quality practices also apply to Google's generative Search features; no separate GEO mechanism was required. | Official recommendation |
| [Bing Webmaster Guidelines](https://www.bing.com/webmasters/help/webmaster-guidelines-30fba23a) | 2026-08-10 | Canonical sitemaps, crawlable links, content clarity, authority, and freshness support Bing discovery and grounding eligibility. | Official recommendation |
| [Bing IndexNow](https://www.bing.com/webmasters/help/indexnow-0z209wby) | 2026-08-10 | IndexNow can notify participating engines of changed URLs, but it is optional and does not prove indexing or ranking. | Official optional protocol |
| [Schema.org documentation](https://schema.org/docs/documents.html) and [WebPage](https://schema.org/WebPage) | 2026-08-10 | Structured data types and properties should represent actual page purpose and visible facts. Schema validity is separate from Google rich-result eligibility. | Official vocabulary |
| [OpenAI publishers and developers FAQ](https://help.openai.com/en/articles/12627856-publishers-and-developers-faq) | 2026-08-10 | OAI-SearchBot access supports ChatGPT search discovery; GPTBot is a separate training control; accessible semantics help agents. | Official requirement/recommendation |
| [Anthropic crawler controls](https://support.claude.com/en/articles/8896518-does-anthropic-crawl-data-from-the-web-and-how-can-site-owners-block-the-crawler) | 2026-08-10 | Claude-SearchBot, Claude-User, and ClaudeBot have distinct search, user-fetch, and training purposes. | Official crawler documentation |
| [Perplexity crawler documentation](https://docs.perplexity.ai/docs/resources/perplexity-crawlers) | 2026-08-10 | PerplexityBot supports search discovery while Perplexity-User is user-triggered; live WAF access should be verified separately from robots.txt. | Official crawler documentation |
| [Robots Exclusion Protocol, RFC 9309](https://www.rfc-editor.org/rfc/rfc9309) | 2026-08-10 | Robots matching and access policy should be evaluated by user agent and path; robots.txt is not an indexing guarantee. | Official standard |
| [llms.txt proposal](https://llmstxt.org/) | 2026-08-10 | The file may aid experimentation, but no consulted provider establishes it as a search requirement or ranking factor. | Experimental/emerging practice |
