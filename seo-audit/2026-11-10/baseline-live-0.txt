	<section class="language-section" aria-labelledby="ecosystem-start"><h2 id="ecosystem-start">Choose a starting point</h2><div class="language-grid"><article><h3>For Kujo programs</h3><p>Start with the <a href="/language/">language runtime</a>, then add <a href="/ecosystem/agents-sdk/">Agents SDK</a>, <a href="/ecosystem/ai-sdk/">AI SDK</a> or <a href="/ecosystem/rag/">RAG</a> for application-specific behavior. SDK programs run in Kujo; packages are installed and versioned separately.</p></article><article><h3>For an existing repository</h3><p><a href="/ecosystem/scout/">Scout</a> and <a href="/ecosystem/scent/">Scent</a> inspect context; <a href="/ecosystem/patchbrief/">PatchBrief</a> and <a href="/ecosystem/changebucket/">ChangeBucket</a> inspect Git changes; <a href="/ecosystem/shipcheck/">ShipCheck</a> checks release readiness. These repository-oriented workflows do not require rewriting your application in Kujo.</p></article></div><p><a href="/development-workflow/">Follow the composable workflow exercise</a>. Each tool's page links to its prerequisites, installation and operating boundaries.</p></section>
