# Raw evidence

`baseline-output/` and `after-output/` are the immutable GitHub Pages artifacts
from deployment runs `33878265415` and `33887274627`. They are excluded from Git
because each duplicates about 82 MB of generated site output. Their tracked
SHA-256 manifests fingerprint every file. The tracked Lens reports, screenshots,
and production diagnostics preserve the bounded browser and edge evidence used
by this audit.
