# Recommendations and measurement plan

Audit date: 2026-09-04

## Immediate after deployment

- Submit the 194-URL sitemap in Google Search Console and Bing Webmaster Tools, then inspect the workflow collection, Publishing House Operator, and Owned Agent Project URLs.
- Resolve or intentionally replace the three anonymously unavailable GitHub destinations in `unresolved.md`.

## 7-day checks

- Record discovered/indexed status, selected canonical, impressions, clicks, and referring queries for the three workflow URLs.
- Compare ChatGPT referral traffic only if analytics access exists; do not infer it from crawler access.
- Review edge logs for crawler access, 404s, and 5xx responses if logs become available.

## 28-, 60-, and 90-day comparisons

- Repeat the exact query and AI-answer benchmark rows with the same country, device, and provider conditions.
- Compare impressions, clicks, CTR, canonical selection, field CWV, backlinks, referrals, and AI citations against this dated baseline without claiming causation from correlation.

## Editorial decisions

- Keep workflow pages source-backed and explicit about released, limited, and experimental boundaries.
- Update release facts as one atomic change across badge, catalog body, source pages, docs, sitemap/social manifests, and validation assertions.
