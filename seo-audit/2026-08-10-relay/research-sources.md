# Primary search guidance consulted

- [Google Search Central: Build and submit a sitemap](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap): sitemap entries should use absolute canonical URLs and represent URLs intended for search results.
- [Google Search Central: Troubleshoot crawling errors](https://developers.google.com/search/docs/crawling-indexing/troubleshoot-crawling-errors): permanently missing pages should return `404` or `410`, and a custom 404 should match the site and offer useful navigation.
- [Google Search Central: Verifying your site — trouble with 404 pages](https://developers.google.com/search/blog/2005/09/verifying-your-site-trouble-with-404): a custom error page must preserve a real `404` response rather than returning `200` or redirecting.
