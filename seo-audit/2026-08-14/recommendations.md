- Confirm the deployed `llms.txt` contains all three section catalogs and all eight Publishing House tools.
- Monitor field Core Web Vitals when a representative dataset becomes available; production lab verification is complete.

- Inspect Google Search Console and Bing Webmaster Tools coverage and sitemap processing when access exists.

## 28-, 60-, and 90-day comparisons

- Compare search queries, impressions, clicks, indexed routes, landing pages, field Core Web Vitals, and a fixed dated AI-citation benchmark.

## Editorial decisions

- Keep volatile release numbers out of evergreen page copy unless the page is explicitly a versioned release note.
- Preserve repository-grounded operating boundaries and avoid claims beyond public source evidence.
- Generate responsive card thumbnails for collection pages to reduce remaining image-transfer cost without changing the Kujo dither style.
