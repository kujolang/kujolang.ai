Provider packages and AI SDK presets connect Kujo to the models and services you already use. Each package keeps the provider's own request and response shape visible, with AI SDK integration where the package supports a normalized workflow.

Choose a provider by where it runs, the protocol it exposes, or the work you need to do. Open any card for a copyable starter, setup commands, and links to the provider package and its documentation.
