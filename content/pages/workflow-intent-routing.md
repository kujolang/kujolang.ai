<section class="workflow-section"><h2>How it works</h2><ol class="workflow-steps"><li>Request one of three allowed intents and a confidence value.</li><li>Apply a local confidence threshold before selecting a handler.</li><li>Write a routing decision for review without dispatching an external action.</li></ol></section>
<section class="workflow-section workflow-failure"><h2>Try a failure. Then recover.</h2><p>Lower the fixture confidence to 0.4. The request goes to human_review. Restore 0.95 to recover. An intent outside the enum exhausts the bounded retries without creating a route.</p><p>Use a fresh extraction to restore the original fixtures. A failed run does not make an older output file current; check the exit status before consuming results.</p></section>

<section class="workflow-section"><h2>Make it yours</h2><p>Change the schema enum and local handler map together. Calibrate a review threshold against labeled requests before using routing decisions in a real queue.</p><h3>Know the boundary</h3><p>Model-reported confidence is not a calibrated probability.
