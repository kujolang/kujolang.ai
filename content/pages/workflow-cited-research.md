<section class="workflow-section"><h2>How it works</h2><ol class="workflow-steps"><li>Retrieve documents that match the supplied search terms.</li><li>Ask the model to answer only from those documents.</li><li>Check citation IDs and exact quotes against retrieved text.</li></ol></section>
<section class="workflow-section workflow-failure"><h2>Try a failure. Then recover.</h2><p>Set input.json.terms to an unmatched word. The application returns insufficient_evidence without calling a model. Restore the terms to recover. An invented citation quote is also rejected.</p><p>Use a fresh extraction to restore the original fixtures. A failed run does not make an older output file current; check the exit status before consuming results.</p></section>
<section class="workflow-section"><h2>Connect a live provider</h2><p>Live mode sends your input to the configured provider and may cost money. The batch and regression examples apply that limit per item.</p><div class="sample-code"><pre tabindex="0"><code>export KUJO_WORKFLOW_MODE=live

<section class="workflow-section"><h2>Make it yours</h2><p>Replace the documents and query terms in input.json. The retriever uses simple lexical matching; replace that step with ranked retrieval when the collection grows.</p><h3>Know the boundary</h3><p>An exact quote proves that text exists, not that it supports every claim in an answer. The result is marked needs_review; check the claim-to-citation relationship.</p></section>
