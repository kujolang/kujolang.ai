## What it covers

Kujo Ecosystem Launch coordinates the complete, evidence-backed path from a release-ready Kujo project to its verified public presence. It establishes the launch contract, invokes focused specialist skills in dependency order, and preserves explicit release and deployment boundaries.

## Released guidance

- Establish the launch type, source repositories, intended release commits, target site, visual mode, and authorization boundaries before editing.
- Prove the product with focused tests, complete repository gates, and clean-install evidence before publication.
- Align versions, changelogs, release notes, tags, GitHub releases, and CI on the exact released commit.
- Synchronize catalog pages, navigation, counts, dither heroes or portraits, Howl social cards, metadata, schema, feeds, and AI-search discovery files.
- Build, audit, deploy only with authority, and verify affected production routes and assets before declaring the launch complete.

## Release boundary

This page reflects the 0.4.1 release published on 2026-08-15. The skill coordinates existing specialist workflows; it does not broaden permissions or replace repository-owned release, visual, audit, deployment, or verification contracts.
