## What it covers

Use when building or substantially reviewing a Kujo-related project that needs cross-ecosystem routing, compact agent-readable code, deterministic AI/offline behavior, and evidence-backed completion. For a narrow syntax question only, prefer kujo-core-language; for one specialized ecosystem tool, prefer its focused workflow skill.

Run the install command from a new working directory. If you already have the released checkout, copy the complete skill folder from it instead of cloning again.

## Released guidance

- Accepted inputs and validation.
- Stable human and machine outputs.
- Ordering and tie behavior.
- Time, token, iteration, output, and collection bounds.
- Host effects and required capabilities.
