## What it covers

Use when running, validating, verifying, comparing, reporting, or integrating SiteProbe website-intelligence crawls, signed `.siteprobe` artifacts, deterministic baselines, or SiteProbe source/tests.

Run the install command from a new working directory. If you already have the released checkout, copy the complete skill folder from it instead of cloning again.

## Released guidance

- validated SiteProbe run.
- pages/links/redirects/metadata/structured-data/sitemap/robots/findings artifacts.
- comparison evidence.
- digest manifest and optional HMAC signature verification result when used.
