## The ecosystem is layered

At the center is Kujo, the language and runtime. Kennel provides the package and dependency foundation. Reusable primitives handle AI providers, agents, structured task contracts, deterministic evaluation, orchestration, observability, guarded tool gateways, and retrieval.

Focused tools sit around those primitives. Some prepare context. Some run bounded workflows. Some collect evidence. Others check release readiness, architecture boundaries, browser behavior, privacy, or cross-artifact drift.

Showcase applications demonstrate complete patterns without claiming to be managed services. AI Chat shows provider-gated chat boundaries. CMS and CRUD API show application architecture. SSG demonstrates deterministic publishing. Intake shows how inbound noise becomes reviewable work.

## Choose the smallest useful path

If you need a scripting language, begin with Kujo. If you need a task contract, add Spec. If you need acceptance checks, add Eval. If you are building an AI application, look at the AI SDK and Watchdog. If you need a complete example, start from a showcase.

The ecosystem page follows this hierarchy so the most foundational projects appear first and the more specialized surfaces stay easy to discover without overwhelming the core story.
