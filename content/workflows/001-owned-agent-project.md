## Outcome

Prove the complete repository-owned Kujo Agent Project lifecycle with inspectable evidence.

## Inputs

- Kujo binary
- Kennel executable
- profile selection

## Evidence and outputs

- generated Agent Project
- doctor JSON
- inspection JSON
- run JSON
- evaluation JSON
- SUMMARY.md

The workflow's evidence contract is: Scaffold, doctor, inspect, run, and Eval JSON plus a summary packet..

## Approval boundaries

- Initial dependency installation may access pinned Git sources; fixture execution needs no provider credential.

## State and recovery

Each invocation creates a new timestamped evidence directory and refuses project overwrite.

## Release boundary

Readiness is **production capable with limitations** in the 0.4.0 local technical preview. Hosted runners, broad live-provider coverage, and enterprise readiness are not implied.
