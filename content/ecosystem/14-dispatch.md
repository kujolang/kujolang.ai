## What it does

Dispatch 1.2.0 runs resumable multi-step workflows with templates, retries, approvals, persisted state, traces, reports, policy controls, signed bundles, and deterministic agent/provider/model routing.

## Why it belongs in Kujo

Auditable workflow orchestration for missions that must pause, resume, and preserve operator control.

## Operating boundary

The published 1.2.0 release provides resumable orchestration and routing. Newer default-branch work adds persisted retrieval preferences, RAG documentation integration, and task/retry observations.

## Release

Dispatch 1.2.0 is the current release. It adds the post-1.1 routing, reliability, lifecycle, artifact, and installation hardening updates. Install from the [v1.2.0 GitHub release](https://github.com/kujolang/dispatch/releases/tag/v1.2.0) or follow the repository's pinned release instructions.
