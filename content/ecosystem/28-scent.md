## What it does

Bounded task context packs with Markdown, JSON, manifests, selected files, changed-file focus, token budgets, and redaction records.

## Why it belongs in Kujo

Give an agent the smallest useful, inspectable context for the job.

## Operating boundary

Context selection and redaction remain reviewable decisions; a pack should not be treated as complete by default.

## Learn more

The repository is the source of truth for current setup, commands, examples, security notes, compatibility, and verification evidence.
