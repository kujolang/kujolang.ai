## What it does

A local retrieval kit for ingest, parsing, chunking, embeddings, hybrid search, namespaces, citations, query APIs, and starter templates.

## Why it belongs in Kujo

Ground agent answers in operator-controlled knowledge with inspectable citations.

## Operating boundary

The published 1.0.0 release provides local retrieval. Newer default-branch work adds documentation example selection, MIME-aware HTTP ingestion, and a private local Kujo-docs snapshot workflow; no public hosted retrieval service is implied.

The repository is the source of truth for current setup, commands, examples, security notes, compatibility, and verification evidence.
