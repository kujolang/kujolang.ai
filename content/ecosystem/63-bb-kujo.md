## Install

```sh
bb plugin install git:https://github.com/kujolang/bb-kujo.git@v0.2.2 --yes
bb theme set plugin:bb-kujo:kujo
```

The plugin provides light and dark appearances, matching syntax and diff colors, Departure Mono for technical text, and bundled Tabler icons. It respects reduced-motion preferences and restores the host appearance when removed.

Read the [BB Kujo guide](https://docs.kujolang.ai/tools/bb-kujo/) and [0.2.2 release](https://github.com/kujolang/bb-kujo/releases/tag/v0.2.2).
