## What it does

An AI-readable design system with tokens, schemas, component templates, layout recipes, generated CSS, and accessibility contracts.

## Why it belongs in Kujo

The consistent visual and semantic foundation used across Kujo ecosystem interfaces.

## Operating boundary

Site Kit is an internal source kit distributed by vendored build artifacts, not a promised public npm service.

## Learn more

The repository is the source of truth for current setup, commands, examples, security notes, compatibility, and verification evidence.
