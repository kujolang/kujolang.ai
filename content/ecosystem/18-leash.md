## What it does

Leash watches agent sessions, classifies risky actions through Kujo policy, and routes approval decisions to a local operator interface with a durable audit trail.

## Why it belongs in Kujo

It makes human approval a concrete runtime boundary instead of an informal convention buried inside an agent transcript.

## Operating boundary

Leash is an active local approval-layer proof. Production use requires deliberate authentication, device trust, notification, network, and policy configuration.

## Source access

The repository is private. Public source access and installation are not available.

## Learn more

The repository contains the daemon, policy examples, agent adapters, mobile application, setup guidance, and current limitations.
