## What it does

Release-readiness scans, checklists, gates, release-note drafts, Markdown and JSON reports, and deterministic verdict semantics.

## Why it belongs in Kujo

Turn release preparation into a visible, repeatable gate instead of a last-minute memory test.

## Operating boundary

ShipCheck is a confidence gate within declared scope, not a universal production certification.

The repository is the source of truth for current setup, commands, examples, security notes, compatibility, and verification evidence.
